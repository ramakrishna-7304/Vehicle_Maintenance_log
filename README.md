# Vehicle Maintenance Log

## Overview
The Vehicle Maintenance Log is a comprehensive application designed to help users track and manage vehicle maintenance records. This project provides a user-friendly interface to ensure that vehicles are properly maintained and kept in optimal condition.

## Features
- Log vehicle maintenance and repairs
- Track service history
- Set reminders for upcoming maintenance
- User authentication and role management
- Multi-vehicle support

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT)
- **Deployment:** Heroku

## Setup Instructions
1. **Clone the repository**  
   ```bash  
   git clone https://github.com/ramakrishna-7304/Vehicle_Maintenance_log.git  
   ```  
2. **Navigate to the project directory**  
   ```bash  
   cd Vehicle_Maintenance_log  
   ```  
3. **Install the dependencies**  
   ```bash  
   npm install  
   ```  
4. **Set up environment variables for the database and JWT**  
5. **Run the application**  
   ```bash  
   npm start  
   ```  

## Usage Guide
- After starting the application, navigate to `http://localhost:3000` in your browser.  
- Register a new account or log in to access the dashboard.  
- From the dashboard, add your vehicles and start logging maintenance records.  
- Set reminders for each maintenance task to receive notifications on time.
